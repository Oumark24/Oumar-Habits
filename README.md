# Oumar Habit Tracker

A modern, distraction-free habit tracker designed to help you build consistency, not just streaks.

Oumar Habit Tracker makes it easy to create habits, monitor your progress, and stay accountable through a clean, intuitive interface. Whether you're building better study habits, improving your health, strengthening your faith, or working toward long-term goals, the app keeps everything organized in one place.

## ✨ Features

- 📅 Daily, weekly, and monthly habit tracking
- 🔥 Streaks and consistency insights
- 📊 Progress statistics and visual analytics
- 🎯 Custom goals and reminders
- 🏷️ Habit categories (Health, School, Fitness, Faith, Productivity, and more)
- 🌙 Beautiful, distraction-free interface
- ☁️ Secure cloud sync (planned)
- 📱 Responsive design for mobile and desktop

## 🎯 Mission

Building great habits shouldn't feel overwhelming. Oumar Habit Tracker focuses on simplicity, motivation, and long-term consistency so you can make meaningful progress every day.

> Small actions, repeated consistently, create extraordinary results.
